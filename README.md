# 꼭꼭아지트 — 3D 위장 숨바꼭질 시제품 (v8)

참고 영상에서 확인한 사람형 캐릭터, 벽에 붙는 자세, 직접 몸에 그리는 위장과 술래 탐색을 바탕으로 다시 만든 브라우저 게임입니다. 이전 탑뷰 버전은 작업 폴더에 보관하고, 현재 앱을 3D로 변경했습니다.

## 바로 해보기
1. 첫 화면은 무늬 없는 흰 캐릭터이며, 색칠 모드로 바로 시작합니다.
2. 캐릭터 표면을 드래그하면 붓으로 그려집니다. 빈 곳 또는 마우스 오른쪽 버튼 드래그로 카메라를 회전합니다. 회전·확대·축소 버튼도 지원합니다.
3. 팔레트, 자유 색상, 붓 굵기, 전체 칠하기, 지우기, 되돌리기, 흰 몸으로 초기화를 지원합니다. 사전 무늬 선택은 제거했습니다.
4. 위장 연습 시작 후 왼쪽 조이스틱으로 움직이고 오른쪽 화면을 드래그해 바라보는 방향을 바꿉니다. PC에서는 WASD/방향키도 지원합니다.
5. 몸과 자세에서 팔 들기/웅크리기/눕기/몸 모으기, 몸 회전과 고정을 선택합니다. 벽 가까이에서는 벽에 붙어 숨기를 사용할 수 있습니다.
6. 색칠 저장하기를 눌러 온라인 친구들에게 반영합니다.
7. 기본 규칙은 위장 3분 → 마지막 숨기 30초 → 술래 탐색 2분입니다. 친구와 탭에서 시간과 정원을 바꿀 수 있고, 방장은 일찍 다음 단계로 넘길 수 있습니다.
8. 술래는 1인칭으로 공간을 둘러봅니다. 대상을 직접 클릭/터치하거나 중앙 조준점을 맞춰 찾기 버튼/스페이스바를 사용합니다. 2.7m 이내이며 장애물에 가리지 않은 대상만 발견됩니다. 찾기 재사용 시간은 2초입니다.
9. 친구와 탭에서 별명으로 방을 만들고 코드로 2~6명이 참여할 수 있습니다.

## 구현
- Three.js 3D 실내 공간, 사람형 캐릭터, 제3자 시점 회전, 술래 1인칭 시점
- 캐릭터 표면 raycast/UV 기반 직접 색칠, 128×128 텍스처, 신체 6부위별 UV 영역, 앞·뒤 별도 색칠
- 벽 부착, 다섯 가지 자세, 몸 회전, 자세 고정, 이동과 충돌
- 참가 코드, 색칠/자세/위치 서버 저장 및 동기화, 재접속, 단계/결과/술래 교대
- 위치/역할/거리/장애물/대상 ID를 서버에서 확인하는 발견 판정
- 준비 및 숨기 단계에서 술래에게 다른 참가자 위치를 보내지 않음
- 터치 및 키보드 조작, 반응형 화면, WebGL 오류 안내

## 한계
현재는 단순한 자체 모델과 맵으로 핵심 게임 방식을 검증하는 시제품입니다. 원작 자산을 사용하지 않습니다. 원작의 물리, 애니메이션, 상세 맵, 관절별 자유 포즈를 재현한 완성판은 아닙니다.

표면 색칠은 한정된 텍스처 해상도를 사용하므로 확대하면 붓 자국의 픽셀이 보일 수 있습니다. 기존 저해상도 그림도 불러오지만 새 UV 배치에서는 예전과 모양이 달라질 수 있습니다.

연습 술래는 정해진 경로를 순찰하고 아주 가까이 접근하면 발견합니다. 위장의 품질을 시각적으로 평가하는 AI는 아닙니다. 사람끼리 할 때는 술래가 화면에서 직접 대상을 지정합니다.

실제 학교 기기와 네트워크는 미검증입니다. 6명 API 동시 입장과 기능 테스트는 통과했으나 30명 학급 전체 부하 시험은 하지 않았습니다. 현재 300ms HTTP 요청과 D1 상태 갱신으로 동기화하므로 정식 운영 전 방 단위 실시간 서버 개선이 필요합니다.

외부 게시/업로드는 승인 대기 상태입니다. 로컬 미리보기와 소스만 준비되었습니다. 그림 맞히기와 블록 퍼즐은 구현하지 않았습니다.

## 로컬 실행
Node.js 22.13 이상, npm, WebGL 지원 브라우저가 필요합니다.

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_high_roulette.sql
npm run dev
```

마이그레이션은 새 로컬 데이터베이스에서 한 번만 실행합니다. 실행 중인 터미널이 안내하는 URL로 접속합니다.

### 함께 플레이하는 흐름 개선 (v6)
참고: https://www.youtube.com/watch?v=gU02R2xA-p8 — 소품의 모양을 따라 팔을 벌리는 위장, 발견 후 관전 장면을 참고했습니다.
- 몸과 자세에서 양팔 각도를 0~160°로 따로 조절합니다. 손을 놓거나 키 조작을 마치면 서버에 저장합니다. 기본 자세 선택, 벽 부착, 다음 판 시작 시 팔 조절값을 초기화합니다.
- 발견된 참가자는 술래 위치를 따라 관전합니다. 카메라는 직접 돌려 볼 수 있으며, 술래가 실제 보고 있는 화면을 그대로 복제하는 기능은 아닙니다. 관전 중 이동과 찾기는 불가능합니다.
- 결과 화면의 어디 숨었는지 보기에서 친구별 마지막 위치와 그림을 공개합니다. 발견된 캐릭터도 다시 표시하며, 선택한 친구의 이름을 표시합니다. 결과 공개 중에는 그림을 수정할 수 없습니다.
검증: 팔 각도 범위 제한, 비정상 값 무시, 기본 자세 및 새 라운드 초기화, 온라인 동기화 통과. 실제 브라우저에서 좌우 팔 0°/160° 자세, 결과 공개와 대상 전환, 서버에서 발견된 참가자의 자동 관전, 결과에서 발견된 캐릭터 재표시 확인.

### 방 규칙과 붓 모양 개선 (v7)
참고: https://www.youtube.com/watch?v=-ma8tZDKFac 의 붓 모양 선택, https://www.youtube.com/watch?v=wg9KWDQ4JZM 의 방 생성·시간 설정 화면을 참고했습니다.
- 둥근 붓·네모 붓·세로 붓을 선택해 자유롭게 칠합니다. 세로 붓은 캐릭터 표면 텍스처의 세로 방향이며, 몸의 자세와 시점에 따라 화면에서 보이는 방향은 달라집니다.
- 위장 시간 1/3/5분, 마지막 숨기 15/30/60초, 찾기 시간 1/2/3/5분, 정원 2/4/6명을 선택합니다. 새 방과 연습 모드에 적용됩니다.
- 온라인 방에서는 방장만 대기 또는 결과 화면에서 규칙을 적용할 수 있습니다. 현재 인원보다 정원을 줄일 수 없고, 정원을 넘는 입장은 서버에서 거절합니다. 각 단계의 종료 시각도 서버 설정을 사용합니다.
- 기존 방은 기본 규칙으로 동작합니다. 연습 모드의 컴퓨터 친구는 최대 3명입니다. 감염 모드와 외부 맵 불러오기는 구현하지 않았습니다.
검증: 설정값 검증, 방장 권한, 진행 중 변경 거절, 정원 초과 입장 거절, 단계별 종료 시각, 설정 저장과 동기화, 붓 모양별 픽셀 범위 테스트 통과. 브라우저에서 2명 연습과 60/15/300초 규칙 적용, 세로 붓의 실제 색칠을 확인했습니다. TypeScript 검사와 프로덕션 빌드 통과.

### 태블릿 조작 개선 (v8)
- 왼쪽 가상 조이스틱으로 모든 방향 이동, 오른쪽 화면 드래그로 시점 조절. 조이스틱은 손을 떼거나 터치가 취소되거나 창을 벗어나면 멈춥니다.
- 색칠 모드에서는 조이스틱을 숨기고 이동을 차단합니다. 시점 잠금은 기본으로 켜며 회전·확대·축소 버튼으로 캐릭터를 살펴봅니다.
- 캔버스는 한 번에 한 포인터만 처리해 추가 손가락이 붓질이나 시점을 덮어쓰지 않도록 했습니다.
- 터치 기기의 버튼·팔레트·슬라이더 영역을 키웠습니다. 술래는 중앙 조준점을 맞추고 찾았다! 버튼을 누릅니다.
- 가로 화면에서 게임 높이를 화면에 맞추고 도구 패널을 별도로 스크롤합니다.
검증: TypeScript와 빌드 통과. 1024×768 브라우저 화면에서 조이스틱으로 실제 좌표 이동, 색칠 전환 시 조이스틱 숨김, 조작 버튼 배치를 확인했습니다. 실제 태블릿의 두 손가락 동시 입력·프레임 속도·학교 네트워크는 아직 미검증입니다.

### 초등학교 3학년용 UI (v9)
- 주요 조작을 1. 이동하기 / 2. 색칠하기 / 3. 숨기로 정리하고 현재 할 일을 짧게 안내합니다.
- 첫 화면에서 이동하기를 누르면 연습이 시작됩니다. 숨은 상태에서 이동하기를 누르면 자세 고정도 풀립니다.
- 자세 고정을 여기에 숨기 / 다시 움직이기로 바꾸고, 붓 굵기를 세 개의 큰 버튼으로 선택합니다.
- 상세 붓 설정과 팔 조절, 방 규칙을 펼침 메뉴 안으로 옮겼습니다. 기능은 유지됩니다.
- 가로 화면은 게임과 도구를 나란히, 세로 화면은 위아래로 배치합니다. 가로 사용을 권장합니다.
